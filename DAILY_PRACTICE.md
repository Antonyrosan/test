# Daily English Practice

## Standard Session — 30–40 Minutes

### 1. Warm-up — 5 minutes
Speak freely about your day, recent work, or something you did yesterday. No script.

### 2. Spontaneous Speaking — 10 minutes
Answer one question without preparing the answer. Keep speaking even if the sentence is imperfect.

### 3. Professional English — 10 minutes
Explain a real work situation, such as:
- An Oracle DBA task you completed
- A database incident
- A patching activity
- A backup or recovery task
- A status update for your manager
- A question for a vendor or colleague

### 4. Correction — 5 minutes
Review only the most important issues:
- Grammar
- Sentence structure
- Unnatural wording
- Fillers
- Missing vocabulary

### 5. Repeat — 5–10 minutes
Answer the same question again using the corrections. The second answer should be clearer and more natural.

## Weekly Rotation

- **Monday:** Fluency + grammar pattern
- **Tuesday:** Work/meeting English
- **Wednesday:** Casual conversation
- **Thursday:** Technical explanation
- **Friday:** Meeting role-play
- **Saturday:** Longer conversation + assessment
- **Sunday:** Light review / rest

## Coaching Rule

The goal is **communication first, perfection second**. Do not stop speaking just because a sentence is not perfect. ChatGPT should allow the response to finish, then provide focused corrections and a natural American-English version.

## Week 1 Speaking Prompts

1. What did you work on today?
2. Explain a recent Oracle DBA task to a non-technical manager.
3. Describe a problem you faced at work and how you solved it.
4. Give a short status update for a database activity.
5. Explain what you are planning to work on tomorrow.
6. Tell me about a recent situation where you had to ask someone for help.
7. Describe your typical workday.
