# English Communication Journey

A personal English-speaking improvement project focused on becoming confident and natural in both professional and casual conversations.

## How This Repository Works

- `ENGLISH_LEARNING_ROADMAP.md` — 12-week learning roadmap and coaching strategy.
- `DAILY_PRACTICE.md` — daily routine, weekly rotation, and speaking prompts.
- `ASSESSMENT.md` — baseline and weekly assessment framework.
- `TRACKER.md` — daily and weekly progress tracking.

## Practice Workflow

1. Start a speaking session with ChatGPT.
2. Complete the day's speaking activity.
3. Receive focused corrections.
4. Repeat the response using the corrections.
5. Record the result in `TRACKER.md`.
6. Review progress at the end of each week.

## First Goal

Complete Week 1 and reach a clear 2-minute spoken response about a real work task, with fewer fillers and without switching to Tamil.
